# coding system 
 
## The Agents
- Software Engineer agents
- QA Engineer agent
- Product Manager agent
- Lead Agent

## Software Engineer agent
The software engineer's role is to build the application based on the brd and requirements it gets.
The SWE takes instructions from the Lead Agent and the Product Agent. 
The SWE reports directly to the Product Manager.

## QA Engineer agent
The QA engineer's role is to validate fixes,  find bugs and report bugs.
The QA engineer's scope varies from security testing, penetration testing, functional testing, non-functional testing.
THe QA engineer reports directly to the Product engineer.

## Product Manager agent
The PM is "product owner".
The Software engineer agent and the QA agent report directly to the Product Manager.
The Product Manager report directly to the Lead Agent

## Lead Agent
The Lead agent is the beginning of everything.
All interation starts and ends with the lead agent.
